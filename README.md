# Drilling Fluid Solids Analysis

Solids analysis calculator for water-base drilling fluids. Runs in any browser, on phone or computer, with no installation and no internet connection needed once the page is open.

**Live version:** https://drillsolidsanalysis.netlify.app

## What it calculates

- Brine correction of the retort for NaCl, KCl, CaCl₂, MgCl₂ or mixed salts, from chloride and cation analysis
- High-gravity and low-gravity solids by mass balance
- Low-gravity solids from mud density for unweighted muds
- Bentonite and drilled solids from MBT, with measured drilled solids and bentonite CEC when available
- Barite and CaCO₃ separated when both are present and the CaCO₃ content is measured
- Weight-up for barite, hematite, ironite, CaCO₃ and LO-WATE

## Units

Metric: SG, % vol, kg/m³, mg/L, meq/100 g.

## Use

Open `index.html` in a browser. Every opening starts with all fields at zero.
